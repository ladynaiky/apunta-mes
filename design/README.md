## Contenido
- `alta-fidelitat/`: las 121 mesas de trabajo (`*.dc.html`: 99 pantallas y variantes, más 22 componentes) y `canvas.json`, el índice con el título de cada mesa.
- `design-system/`: `README.md` (guía de marca), `tokens.json`, `correcciones-md3.md`, `sugerencias.md`, `verificacion.md` y `components/` (una guía por componente y `bundle.css`).

## Aviso
Las mesas `.dc.html` **no se pueden abrir directamente en el navegador**: necesitan el motor del editor de Claude Design (`support.js`), que no está incluido. Sirven para leer el HTML, los textos, los colores y la lógica de cada pantalla. Para verlas, usa el enlace.

Las decisiones que prevalecen sobre estos archivos están en `../CLAUDE.md` (parte 2).
